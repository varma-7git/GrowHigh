# GrowHigh Frontend (React, Create React App + Bootstrap)

Run in Command Prompt (Node.js LTS must be installed: nodejs.org):
```
cd growhigh-frontend
npm install
npm start
```
Opens http://localhost:3000. The backend must be running at http://127.0.0.1:8000 (see `.env`: REACT_APP_API_URL).

Pages so far: Landing `/`, Login `/login`, Register `/register`, Forgot password `/forgot-password`, and placeholder dashboards `/student`, `/faculty`, `/admin`.
